# 发布说明 — Itutu no Nandai MOD+（五つの難題MOD+）2.90-1.21.1

> 面向：发布方与玩家。玩家向细节（差异清单 / 配置迁移 / FAQ / 已知问题）一律以
> [`USER_MIGRATION.md`](USER_MIGRATION.md) 为准，本文只做总览与发布结论。

## 1. 这是什么

东方弹幕模组「五つの難題MOD+」（THKaguyaMod v2.90，Forge 1.7.10）到
**Minecraft 1.21.1 + NeoForge** 的完整移植。移植原则是**玩家可见行为与旧版一致**；
无法等价实现的部分均已文档化（见迁移指南 §3 差异清单与 §5 已知问题 22 条）。

## 2. 运行环境

| 项 | 值 |
|---|---|
| Minecraft | 1.21.1 |
| 加载器 | NeoForge **21.1.252** 或更高的 21.1.x |
| Java | **21**（必需） |
| modid | `thkaguyamod`（旧版 `THKaguyaMod` 在现代加载器不合法，已全小写） |
| 发布文件 | `thkaguyamod-2.90-1.21.1.jar` |
| 前置模组 | 无 |
| 安装 | 放入 `mods/`；单人装客户端，**多人双端都要装** |

## 3. 内容规模

- **126 物品 + 10 方块物品 = 136 项**（含 **35 张符卡**）、110 条配方
- **46 个实体类型**：杂兵/首领/商人（琪露诺、露米娅、屠自古、莉格露、灵梦、神子、早苗、咲夜、霖之助……）、道具与效果实体、弹幕与法阵
- 2 个创造模式标签页（主标签 + 符卡标签）
- 弹幕工作台 / 激光弹幕工作台 GUI、早苗自定义商店界面、万宝槌转换台（潜行右键）
- 双向自定义网络包（商店交易表下发 / 选择上传）
- 14 个生物群系生成修饰器 + 地牢箱万宝槌战利品修饰器（GLM）
- 配置文件 `config/thkaguyamod-server.toml`（旧 `.cfg` 不通用；逐项对照见迁移指南 §4）

## 5. 本次发布前实测发现并修复的问题

- **妖精/幽灵/使魔等无法生成（核心内容级，台账 I11）**：弹幕样式表的注册调用在移植中遗漏
  （原作在初始化时调用一次），样式表恒空导致妖精系实体构造即抛异常，召唤与自然生成全部失败。
  已在配置加载完成后补回调用（样式随弹幕难度重建，含难度 0 的原作兜底），并保证重载幂等。
- **魔人镜冠导致客户端崩溃（必崩级，台账 I10）**：渲染器在同一缓冲源上交叉取用两种渲染类型后
  复用已失效的旧顶点写入器（`Not building!`）。已按 1.7.10 三次提交的顺序语义修复，同类
  写法全树扫描仅此一处。
- **弹幕/激光/符卡对怪物零伤害（核心玩法级，台账 I8）**：1.7.10 的 `canBeCollidedWith`
  身兼「可碰撞 / 可被准星选取 / 可被弹丸命中」三职，1.21.1 拆为三个方法且原版生物不再覆写
  碰撞判定。移植只搬了第一职，命中扫描过滤器把全部生物排除。已按新版语义修复全部 7 处
  命中扫描，并为 12 个实体补齐准星选取（附带恢复：打拳反弹弹幕、隙间染色、迷你八卦炉与
  银刀的回收、小神灵/替身人偶等实体交互）。
- **魔法扫帚下骑后不停且无法破坏（台账 I9）**：同一三职拆分问题导致准星选不中扫帚
  （无法攻击破坏/再骑乘）；另有无人时的减速代码只改了局部变量从未生效。均已修复，
  现可正常破坏回收、下骑后缓降停止。
- **延迟弹渲染崩溃（客户端必崩级，台账 I7）**：符卡/BOSS 的延迟弹在"光预告"阶段按
  动画帧奇偶索引颜色数组，延迟计数为负时奇数帧下标为 -1 导致 `ArrayIndexOutOfBoundsException`。
  系 1.7.10→1.21.1 转录笔误（原作该处用弹色下标，帧奇偶只驱动贴图 UV）。已修复并通过全量回归；
  同类数组下标用法已在全部渲染器中普查，无其他隐患。
- **扫帚下骑后微颤不止（台账 I13）**：1.21.1 的 `move()` 着地不清零垂直速度（旧版会吃掉），
  照抄旧版的着地补偿在新版变成净上浮。已按新版物理语义修正，滑距与衰减经 GameTest 逐式验证与旧版同值。
- **右键使用物品时人物趴下（台账 I14）**：新版的"自动匍匐"机制把模组弹幕/效果实体的碰撞盒
  计入玩家站立空间 → 右键时被迫趴下。已让 5 类实体退出推挤碰撞（瞄准/命中/打拳反弹不受影响）。
- **扫帚飞行时模型整圈乱转（台账 I15）**：旧版角度不回卷 + 新版渲染插值把 360° 整数倍整段走完。
  已按新版插值惯例修复（纯函数数值验证：修正前持续转向最大扫掠 11 圈 → 修正后 0）。
- **控制棒（核弹）不破坏地形（台账 I16）**：旧版该功能**从未接线**（爆炸破坏分支不可达，
  有字节码证据）——本版按设计意图实现（受配置 `Master Spark Destroys Blocks` 门控，默认开）。
  **属有意偏离旧版**，如需严格忠于原作可回退（迁移指南 §3.4 有登记）。
- 另：花田尖叫者特定窗口被击杀后实体永不移除（旧版同源 bug，台账规则修复）、
  使魔/幽灵在配置重载空窗的构造崩溃、商店/合成台若干小项修复——完整清单见台账 I1-I16。
- **魔法扫帚手动操舵完整实装**（原"视线前进"降级方案关闭）：W 前进 / S 后退 / A·D 横移 /
  空格悬停，骑乘抖动消除；巡航速度修复旧版限速笔误后恒定（约 +10%）；移动为客户端权威
  （与原版船同级，服务器反作弊注意事项见迁移指南 §5 第 1 条）。

## 6. 重要须知（发布前务必阅读）

1. **不支持旧存档迁移**：1.7.10 存档无法带入本版，也没有提供修复器；补偿指引见迁移指南 §2。
2. **玩家可见差异**：配方/界面/外观/音效/玩法/生成 6 类差异逐条列于迁移指南 §3；
   **已知问题 22 条**列于 §5（扫帚操舵简化、时停天空暗化降级、4 类音效原版占位、
   无刷怪蛋、玉枝充能图标不变、折叠伞图标不变色等），均不致命。
3. **待发布方确认事项 21 条**列于迁移指南附录 A，其中**发布前必须拍板**的：
   作者署名与授权文本（当前为模板占位 `All Rights Reserved`）、反馈渠道链接
   （`issueTrackerURL` / `displayURL` 未填写）、万宝槌地牢刷新率（0.77% vs 原设计意图 5%）。
4. 明确不移植的旧版半成品（楼观旋风刃、宝塔、SC_31 等）已在迁移指南附录 A 第 21 条声明。
